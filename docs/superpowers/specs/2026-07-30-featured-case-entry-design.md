# 案例详情入口置顶设计

## 目标

让 `/cases` 中已有的工业卷帘门图文案例成为首个可见入口，同时保持现有按地点分组的页面结构。

## 已确认方案

- 保留稳定详情地址 `/cases/hualian-south-industrial-roller-door`。
- 展示地点统一缩短为“枣强门市”，不再显示“枣强华联南边门市”。
- 将该案例标记为置顶，使其地点导航和案例分组都排在第一位。
- 卡片增加“新案例”“图文实拍”标签，颜色沿用现有绿色和金色设计变量。
- 不新增重复推荐区，也不在分组中重复渲染案例。

## 数据与排序

案例数据增加 `featured: true` 和 `badges`。分组函数优先排列包含置顶案例的地点，其余地点继续按案例数量和中文地点名称排序；同一地点内置顶案例排在普通案例之前。

## 验证

- 自动测试验证短地点名、两个标签、置顶案例所在分组及卡片均为首位。
- Next.js 生产构建必须成功。
- 构建后的 `/cases` HTML 中，详情链接必须早于普通案例卡片出现。
